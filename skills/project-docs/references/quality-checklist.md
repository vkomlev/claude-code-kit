# Чеклист качества документации

Финальная верификация перед выдачей результата пользователю.

## S1 — Критично (документация не работает)

### CLAUDE.md
- [ ] Файл существует в корне проекта
- [ ] Есть секции: Project Overview, Tech Stack, Key Commands
- [ ] Markdown валиден (балансы ```, заголовков)
- [ ] UTF-8 без BOM

### README.md
- [ ] Файл существует в корне проекта
- [ ] Есть блок "Быстрый старт" с исполнимыми командами
- [ ] Markdown валиден

### AGENTS.md
- [ ] Существует (симлинк на CLAUDE.md или копия)
- [ ] Если копия — вверху note о ручной синхронизации

## S2 — Важно (снижает качество)

### Размеры
- [ ] CLAUDE.md ≤ 200 строк
- [ ] README.md ≤ 150 строк
- [ ] Детали вынесены в `docs/ai/` и `docs/`

### Ссылки
- [ ] Все ссылки из CLAUDE.md на `docs/ai/*` резолвятся (файлы существуют)
- [ ] Все ссылки из README.md на `docs/*` резолвятся
- [ ] Нет битых relative-ссылок на файлы кода

### Разделение слоёв
- [ ] CLAUDE.md — сухие факты, без мотивации и маркетинга
- [ ] README.md — нарратив для человека, с контекстом и примерами
- [ ] Нет дублирования фактов между CLAUDE.md и README.md (кроме Tech Stack — допустимо)

### Содержание AI-слоя
- [ ] `docs/ai/architecture.md` — есть компоненты и потоки данных
- [ ] `docs/ai/workflows.md` — описаны типовые сценарии разработки
- [ ] `docs/ai/errors.md` — есть хотя бы 2-3 known issues или антипаттерна
- [ ] `docs/ai/glossary.md` — доменные термины (если проект доменный)

### Содержание human-слоя
- [ ] `docs/install.md` — системные требования + пошаговая установка
- [ ] `docs/usage.md` — команды с примерами копипаст
- [ ] `docs/configuration.md` — таблица env-переменных
- [ ] `docs/troubleshooting.md` — 3+ типовых проблем

### Безопасность
- [ ] Нет реальных credentials, токенов, паролей
- [ ] Только имена env-переменных, не значения
- [ ] `.env` в `.gitignore` (проверить)

## S3 — Косметика

- [ ] Порядок секций в CLAUDE.md: Overview → Stack → Architecture → Structure → Commands → Conventions → Workflows → References
- [ ] Нет TODO/FIXME оставленных в артефактах
- [ ] Нет плейсхолдеров `{{...}}` — все заменены или помечены как gap
- [ ] Код-блоки с указанием языка (```bash, ```python)

## Команды верификации

```bash
# Размеры
wc -l CLAUDE.md README.md

# Битые ссылки (grep для markdown-ссылок)
grep -oE '\]\([^)]+\)' CLAUDE.md README.md docs/**/*.md

# Плейсхолдеры
grep -rn '{{' CLAUDE.md README.md docs/

# BOM-проверка (Unix)
file CLAUDE.md README.md | grep -i bom

# Симлинк AGENTS.md (Unix)
ls -la AGENTS.md
```

## Gap-репорт

Если в документации остались незаполненные разделы — перечислить их в отчёте:
- Секции с плейсхолдерами `{{...}}`
- Разделы с пустым содержимым
- Флоу, которые не удалось определить из кода
- Env-переменные без описания

Пользователь должен заполнить gaps вручную или запустить `/project-docs update` позже с новыми данными.
