# SEO-плейбук (справочник seo-specialist)

Рабочий набор для малого бизнеса РФ. Приоритет — Яндекс (доля рынка РФ), затем Google. Механика меняется ежеквартально — перед применением сверяться `WebSearch`.

## 1. Яндекс vs Google — ключевые различия

| Фактор | Яндекс | Google |
|---|---|---|
| Главное | Поведенческие + коммерческие факторы, ИКС | E-E-A-T, helpful content, ссылки |
| Поведенческие | Очень сильны (CTR, время, отказы, возвраты в выдачу) | Учитываются слабее и косвенно |
| Коммерческие факторы | Критичны для услуг: цены, контакты, ассортимент, доверие | Отдельного «коммерческого» сигнала нет |
| Авторитет | ИКС (индекс качества сайта) | Ссылочный профиль, авторство, бренд-сигналы |
| Свежесть/апдейты | Частые, поведенческие апдейты | Core Updates, Helpful Content System |
| Инструменты | Яндекс.Вебмастер, Метрика, Wordstat | Search Console, GA4, Keyword Planner |

Вывод для соло-бизнеса РФ: **сначала Яндекс** (поведенческие + коммерческие + локальное), Google — параллельно на технике и контенте. Накрутка поведенческих — прямой путь под фильтр, не предлагать.

## 2. Чеклист техаудита
**Индексация и доступность**
- robots.txt не блокирует нужное; sitemap.xml актуален и в Вебмастере/Search Console
- нет случайного `noindex`, нет дублей в индексе
- HTTPS, нет смешанного контента, корректные редиректы (301, без цепочек)

**Скорость и Core Web Vitals**
- LCP < 2.5с, INP < 200мс, CLS < 0.1 (проверять PageSpeed Insights / Вебмастер)
- сжатие изображений (WebP), lazy-load, кэш

**Мобильность** — адаптивная вёрстка, тап-цели, читаемый шрифт (mobile-first у обоих ПС)

**On-page структура**
- один H1 на странице, логичная иерархия H2-H3
- title (до ~60 симв, вхождение запроса в начале), description (до ~160 симв, призыв)
- ЧПУ-URL (человекочитаемые, без параметров-мусора)
- alt у изображений
- нет дублей title/description по сайту

**Микроразметка** — schema.org: `Organization`, `BreadcrumbList`, `Course`, `FAQPage`, `Article`, `LocalBusiness` (см. geo-aeo.md)

**Коммерческие факторы (для Яндекса, услуги)** — цены, телефон/мессенджеры на видном месте, страница «О компании»/эксперте, отзывы, реквизиты, оферта, разнообразие услуг.

**Приоритизация находок:** критично (рушит индексацию/ранжирование) / важно (тормозит рост) / косметика.

## 3. Семантическое ядро
1. **Сбор:** маска-запросы → Wordstat (оператор), подсказки поиска, «вместе с этим ищут», блок «люди спрашивают», конкуренты, `WebSearch` для расширения. Инструменты оператора: Яндекс Wordstat (бесплатно), Key Collector, бесплатные — Букварикс, Мутаген (лимиты).
2. **Интент** каждого запроса:
   - информационный («как выбрать курсы программирования ребёнку») → статья/блог
   - коммерческий («курсы python для подростков цена») → страница услуги
   - навигационный/брендовый → главная/бренд-страница
3. **Кластеризация** по общности выдачи и интенту: один кластер = одна страница. Не пытаться ранжировать одну страницу по разным интентам.
4. **Приоритет кластеров:** частотность × коммерческость × реалистичность выхода в топ (низкоконкурентные длинные хвосты — быстрые победы для малого сайта).
5. Реальные частотности — только из Wordstat оператора; в ТЗ без данных — пометка `[проверить частотность]`.

## 4. On-page оптимизация
- Вхождение главного запроса: title (начало), H1, первый абзац, естественно по тексту, alt.
- LSI/сопутствующие слова — из подсветок Wordstat и «вместе ищут», не переспам.
- Структура под интент: полностью закрыть вопрос пользователя (иначе он вернётся в выдачу → плохой поведенческий у Яндекса).
- Внутренняя перелинковка: связать кластеры, вести вес на коммерческие страницы.
- Уникальность: без копипаста, без генеренного «водного» текста (Helpful Content / поведенческие накажут).

## 5. Контент-стратегия
- Информационные статьи под верх воронки (родитель выбирает) → ведут на коммерческие страницы.
- Закрывать реальные вопросы ЦА (родитель: «безопасно ли», «что даст ребёнку», «сколько стоит», «с какого возраста»).
- Регулярность важнее объёма. Обновлять старые статьи (свежесть — фактор).
- E-E-A-T: указывать автора-эксперта, опыт, ссылки на источники — важно и для Google, и для ИИ-ответов.

## 6. Ссылки и авторитет (РФ-реалии)
- Естественные упоминания: каталоги (Яндекс Бизнес, 2ГИС, профильные), отзовики, экспертные площадки (VC, Habr, Дзен), гостевые статьи.
- Крауд-маркетинг: полезные ответы в тематических чатах/форумах со ссылкой к месту.
- **Не покупать** ссылки-помойки, прогоны, PBN — риск фильтра. Качество > количество.
- ИКС Яндекса растёт от поведенческих, упоминаний бренда и качества сайта, а не от «ссылочной массы».

## 7. Локальное SEO
- Яндекс Бизнес + Google Business Profile: полные карточки, верные категории, услуги, фото, часы, отзывы.
- NAP-консистентность (Name-Address-Phone одинаковы везде).
- Геозапросы («курсы программирования Екатеринбург») в title/H1 нужных страниц.
- Отзывы — системный сбор: это и локальный сигнал, и коммерческий фактор, и доверие для ИИ-ответов.

## 8. Метрики и отчётность
- **Позиции** по ядру (сервисы съёма — оператор; или ручная проверка ключевых).
- **Органический трафик** и его качество (Метрика/GA4): визиты, отказы, глубина, конверсии в заявку.
- **Видимость** (доля запросов в топ-10).
- **ИКС** (Вебмастер), Core Web Vitals.
- **ИИ-упоминания** — см. geo-aeo.md (мониторинг цитирования в Нейро/AI Overviews/ChatGPT/Perplexity).
- Отчёт: что сделано → что сдвинулось → что дальше. Не отчёт ради отчёта.

## 9. Стоп-лист (чёрное SEO — запрещено)
Накрутка поведенческих факторов, клоакинг, дорвеи, скрытый текст/ссылки, покупные ссылки-помойки, переспам ключами, генеренный «водный» контент, чужой копипаст. Всё это ведёт к фильтрам Яндекса (АГС, Баден-Баден) и Google (спам-апдейты). Скилл предлагает только белые методы.
