# Директ-плейбук (справочник yandex-direct-specialist)

Ниша онлайн-образования, малый бюджет. Директ часто меняет форматы — **перед применением обязательно `WebSearch` актуального состояния (2025–2026)**; ниже — устойчивые принципы, а не заморозка текущих названий.

## 1. Мастер кампаний vs режим эксперта
- **Мастер кампаний** — упрощённый режим: минимум настроек, автоматика подбирает аудиторию/площадки. Плюс малому бизнесу — быстрый старт, работает на малом трафике. Минус — мало контроля, риск нецелевых показов без жёстких минус-слов.
- **Режим эксперта** — полный контроль: структура, ставки, минус-фразы, площадки. Нужен, когда есть данные и опыт.
- Рекомендация: новичку/микробюджету — начать с Мастера на горячем ядре + минус-слова; при росте — эксперт.
- **ЕПК (Единая перфоманс-кампания)** и объединения форматов — Яндекс периодически меняет; проверять, что актуально, `WebSearch`.

## 2. Поиск vs РСЯ
- **Поиск** — показы по запросу в выдаче. Горячий спрос, выше конверсия, дороже клик. Для образования — ядро: «курсы программирования для детей», «репетитор ЕГЭ информатика».
- **РСЯ (Рекламная сеть Яндекса)** — баннеры/тексты на сайтах-партнёрах. Холоднее, дешевле, широкий охват; хорошо для **ретаргета** и допрогрева.
- Старт малого бюджета: **Поиск по горячим запросам** + **РСЯ-ретаргет** на тех, кто заходил на сайт/лендинг, но не оставил заявку.

## 3. Семантика и минус-фразы
**Сбор:** Wordstat (частотности — оператор), подсказки, конкуренты, `WebSearch`. Группировать по интенту.
**Горячесть запросов** (приоритет бюджета):
- транзакционные («записаться», «цена», «купить курс») — вверх;
- окологорячие («курсы python для подростков») — далее;
- информационные («как научить ребёнка программировать») — осторожно, дорого конвертятся, лучше в РСЯ/контент.
**Минус-фразы (обязательно):** отсекать нецелевое — `бесплатно, скачать, торрент, вакансия, работа, зарплата, отзывы сотрудников, самостоятельно, своими руками, реферат, вуз, институт` и т.п. под нишу.
**Кросс-минусация** между группами — чтобы запрос показывался по нужной группе, а не конкурировал сам с собой.
**Операторы соответствия:** `"фраза"` (фиксирует состав), `!слово` (фиксирует форму), `[порядок слов]`. При малом бюджете точность важнее охвата.

## 4. Цели и оптимизация (Метрика)
- Директ без целей Метрики = слепая трата. Настроить цели: заявка (отправка формы), звонок, запись на пробное, клик по мессенджеру.
- **Микроконверсии при малом трафике** — критично: клик по телефону, N секунд на странице, скролл, просмотр программы. Дают автостратегиям данные для обучения, когда заявок мало.
- **Выбор стратегии по объёму конверсий:**
  - мало конверсий (< ~10/нед) → оплата за клики + ручной/недельный контроль, или Мастер; автостратегии «за конверсии» пока не потянут (нет данных для обучения);
  - достаточно конверсий → перейти на оптимизацию/оплату за конверсии.
- UTM-разметка всех объявлений → сквозная аналитика (`/marketing-analyst`).

## 5. Бюджет малого бизнеса
- Минимальный рабочий бюджет зависит от ниши/региона/конкуренции — ориентиры смотреть `WebSearch`/прогноз Директа, не называть цифру из памяти.
- **Недельный лимит** вместо неконтролируемого расхода.
- Прогноз: клики × конверсия в заявку (гипотеза) = заявки; расход / заявки = цена заявки; сверить с допустимым CAC (LTV/CAC ≥ 3).
- **Правило старта:** узкое горячее ядро + жёсткие минусы + ограниченный лимит → 1–2 недели данных → расширять то, что даёт заявки. Не открывать широкий охват/РСЯ на всё сразу при малом бюджете.

## 6. Тексты объявлений
- Заголовок 1: запрос + оффер/выгода; Заголовок 2: усиление (гарантия/пробное/результат). Уложиться в лимиты символов (проверять актуальные).
- Заполнять **всё**: быстрые ссылки (разделы: программа, цены, отзывы, пробное), уточнения, отображаемую ссылку, визитку, цену — это повышает CTR и качество, снижает цену клика.
- Релевантность цепочки **запрос → объявление → посадочная страница**. Клик на нерелевантный лендинг = деньги на ветер.
- Двойная ЦА: объявление для родителя (покупатель) отличается от «для подростка».

## 7. Модерация образовательных услуг (важно)
- Реклама образовательных услуг в Яндексе может требовать подтверждения: **лицензии на образовательную деятельность** либо корректного указания статуса (ИП/самозанятый/частный преподаватель без лицензии — где это допустимо).
- Требования меняются — проверять актуальное `WebSearch` и в справке Директа перед запуском.
- Скилл не решает вопрос лицензии за оператора: выносит **что подготовить** (документы/формулировки), чтобы пройти модерацию.
- Не обещать в объявлениях гарантированный результат («100 баллов ЕГЭ»), не вводить в заблуждение о статусе — отклонят на модерации.

## 8. Стоп-ошибки (слив бюджета)
- Запуск без минус-слов и кросс-минусации.
- Широкие ставки и широкое соответствие на малом бюджете.
- Нет целей в Метрике → нельзя оптимизировать.
- Сложная автостратегия при 2–3 конверсиях в неделю (не на чем учиться).
- Поиск + РСЯ в одной кампании вперемешку (разная логика, разные ставки).
- Объявление ведёт на общую главную вместо релевантной посадочной.
- Показы не в том регионе/времени, игнор отчёта по поисковым запросам.
- Масштабирование до накопления данных.
