# Чеклист аудита skill

Используется claude-booster при проверке любого SKILL.md.

## S1 — Критично (skill может не работать)

- [ ] Есть поле `name` во фронтматтере
- [ ] Есть поле `allowed-tools` во фронтматтере
- [ ] Есть секция `## Порядок работы` (или `## Workflow`)
- [ ] Файл не пустой и не повреждён
- [ ] YAML фронтматтер корректно закрыт (`---`)

## S2 — Важно (снижает качество)

- [ ] Есть поле `version` во фронтматтере
- [ ] Есть секция `## Роль` (или аналог с описанием роли)
- [ ] Есть секция `## Когда использовать`
- [ ] Есть секция `## Контракт результата` (или `## Output Contract`)
- [ ] Есть секция `## Правила качества` (или `## Quality Rules`)
- [ ] Язык описания — русский
- [ ] `description` во фронтматтере на русском
- [ ] Заголовки секций на одном языке (не смешаны RU/EN)

## S3 — Косметика (не влияет на работу)

- [ ] Секции идут в стандартном порядке (Роль → Когда → Порядок → Контракт → Правила)
- [ ] Нет дублирования инструкций из других skills
- [ ] Нет очевидных шагов ("прочитай задачу")
- [ ] Размер соответствует сложности (см. standard.md)

## Исключения

- gstack бинарники (`dist/`, `node_modules/`) — не трогать
- SKILL.md в `~/.claude/skills/gstack/` — обновлять только текст, не сборку
- `ceo-review` и `eng-review` — сложные skills, S3 не применять строго
