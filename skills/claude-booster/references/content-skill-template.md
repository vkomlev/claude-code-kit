# Шаблон контент-ориентированного skill

Используется `/claude-booster` (Режим C) при создании новых контент-skills.
Скопируй структуру ниже, заполни плейсхолдеры {}. Пути к материалам бренда (voice-guide,
глоссарий, шаблоны) — подставь свои; если таких материалов нет, опирайся на ai-humanness.md.

```markdown
---
name: {skill-name}
version: 1.0.0
description: |
  {Описание на русском: что делает skill, для какого типа контента.}
allowed-tools:
  - Read
  - Edit
  - Write
  - Bash
  - Glob
  - Grep
  - AskUserQuestion
---

## Роль
{Роль}: создаю {тип контента} по шаблонам и стиль-гайдам проекта.

## Когда использовать
- {Триггер 1}
- {Триггер 2}
- {Триггер 3}

## Порядок работы

### Шаг 0: Загрузка контекста (ОБЯЗАТЕЛЕН)
1. Прочитать `~/.claude/skills/claude-booster/references/ai-humanness.md` — чеклист человечности, 12 AI-маркеров, стоп-лист канцелярита. **Обязателен для всех копирайт-skills.**
2. Прочитать гайд по голосу/тону и запреты бренда (`<путь к материалам>/voice-guide.md`), если ведётся.
3. Прочитать глоссарий/терминологию (`<путь к материалам>/glossary.md`), если ведётся.
4. Прочитать шаблон под тип контента (`<путь к шаблонам>/{type}/{template}.md`), если ведётся.
5. Прочитать материалы по предметной области и специфике платформы, если есть.
6. **Пропуск пункта 1 (ai-humanness.md) = СТОП, вернуться и прочитать.**
8. Если информации недостаточно — задать уточняющий вопрос, НЕ додумывать.

### Шаг 1: Уточнение задачи
Если в задаче не указано:
- Тип контента → спросить
- Целевая аудитория → спросить
- Платформа → спросить
- Объём (если отличается от шаблона) → спросить

### Шаг 2: Генерация
{Описать шаги генерации для конкретного типа контента}

### Шаг 3: Верификация
Перед выдачей результата — сверить:

**Содержание:**
- [ ] Объём соответствует limits из frontmatter шаблона?
- [ ] Тон соответствует voice-guide.md?
- [ ] ВСЕ пункты задания покрыты? (непокрытый = незавершённая задача)
- [ ] Нет выдуманных фактов? (только из references/)
- [ ] Термины из glossary.md?
- [ ] Платформенные ограничения соблюдены?

**Человечность (ai-humanness.md, Часть 4):**
- [ ] Нет цепочек из 2+ деепричастий (M1)
- [ ] Нет связок `служит`/`выступает`/`представляет собой` (M2)
- [ ] Списки не все по 3 пункта (M3)
- [ ] Нет synonym cycling (M4)
- [ ] Нет `важно отметить`/`стоит учитывать`/`следует помнить` (M5)
- [ ] Нет пустых эпитетов `уникальный`/`потрясающий`/`невероятный` (M6)
- [ ] Нет канцеляризмов `данный`/`осуществить`/`в рамках` (M7)
- [ ] Тире ≤ 3 на 1000 слов (M8)
- [ ] "Не X, а Y" — максимум 1 раз (M9)
- [ ] Минимум 3 коротких предложения (≤7 слов) на каждые 10 (M10)
- [ ] Есть хотя бы один "шов" без плавного перехода (M11)
- [ ] Нет `давайте рассмотрим`/`обратите внимание` (M12)
- [ ] Есть хотя бы один приём из H1-H7 (парцелляция, ремарка, шов)

Нарушено 3+ пункта — переписать. 1-2 — исправить точечно.

## Контракт результата
- `Контент` — готовый текст по шаблону
- `Метаданные` — шаблон, платформа, объём (слов), версия voice-guide
- `Чеклист` — результат верификации (все пункты)
- `Отклонения` — если что-то не удалось покрыть и почему

## Правила качества
- **Тон:** только из voice-guide.md, не переключать без команды
- **Человечность:** соблюдать ai-humanness.md (12 AI-маркеров). Текст, который звучит как GPT, — брак
- **Факты:** только из references/, нет источника = сообщить пользователю
- **Объём:** строго по limits шаблона
- **Ритм:** чередовать длинные и короткие предложения
- **Тире:** считать — максимум 3 на 1000 слов
- **Полнота:** непокрытый пункт задания = незавершённая задача
- **Контекст:** пропуск voice-guide/glossary/references/ai-humanness = СТОП
- **Уточнения:** при неясности — спросить, не додумывать
```
