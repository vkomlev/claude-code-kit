# Каталог скиллов (42)

Скиллы вызываются командой `/имя` или подбираются агентом автоматически. Ниже —
что делает каждый и когда его брать. Сгруппировано по назначению.

---

## Планирование и постановка задачи

| Скилл | Что делает |
|---|---|
| `/spec-writer` | Размытую задачу → план с границами, рисками и критериями готовности. Точка входа для нечётких задач. |
| `/change-plan-architect` | План внедрения изменения: анализ кода, контрактов, зависимостей, поиск блокеров. Задачи средней сложности. |
| `/tech-spec-composer` | ТЗ для агента-исполнителя: явный контекст, ограничения, правила стека, критерии приёмки. |
| `/ceo-review` | Переосмысление плана в режиме фаундера: оспорить предпосылки, найти лучший продукт. 3 режима охвата. |
| `/eng-review` | Инженерный обзор плана (техлид): архитектура, потоки данных, граничные случаи, тесты, производительность. |
| `/architect-system-analyst` | Архитектор + системный аналитик: картина AS-IS, пробелы в контрактах, минимальный TO-BE с ADR и C4-light. |
| `/ai-orchestrator` | Оркестрация сквозной поставки: уровни контекста minimal/standard/full, маршрутизация по ролям скиллов, гейты. |

| Скилл | Что делает |

| `/executor-pro` | Критичные и многомодульные правки после плана: контракты, БД, миграции, production-логика. |
| `/fastapi-api-developer` | Backend на FastAPI + PostgreSQL: эндпоинты, багфиксы, миграции Alembic, log-driven диагностика. |
| `/db-check` | DBA: аудит схемы, проверка данных, диагностика производительности, безопасные миграции и правки данных. |
| `/telegram-ux-flow-designer` | UX-флоу Telegram-ботов на aiogram / aiogram-dialog: меньше экранов и кликов при сохранении ясности. |
| `/site-researcher` | Разведка сайта: robots/sitemap, DOM под парсинг, SEO-аудит, поиск скрытых API-эндпоинтов, конкуренты. |

## Ревью и контроль качества

|---|---|

| `/feature-completeness-review` | Доведён ли функционал до конца: данные на экране есть, а действий с ними нет. Не про визуал — только отчёт. |
| `/design-consultation` | Дизайн-система с нуля: эстетика, типографика, цвет, раскладка + страницы-превью. Создаёт DESIGN.md. |

## Типовые связки

- **Фича с нуля:** `/spec-writer` → `/change-plan-architect` → `/executor-pro` → `/review-gate` → `/ship`.
- **Быстрая правка:** `/executor-lite` → `/qa-fix`.
- **Новый проект:** `/project-docs` (обвязка) → далее по задачам.
- **Запуск продукта (маркетинг):** `/marketing-strategist` → брифы в `/seo-specialist` / `/smm-specialist` / `/yandex-direct-specialist` → тексты копирайтером → `/marketing-analyst` (итоги).
- **Улучшить сам инструмент:** `/claude-booster` (аудит скилла, новый скилл, правка настроек).
